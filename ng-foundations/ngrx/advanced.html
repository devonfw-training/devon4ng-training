Scalable Store Patterns

Feature Store Setup

                                
                                StoreModule.forFeature('feature', featureReducer);
    or without ng modules 
                  
                provideStore({ [featureKey]: featureReducer })
  • One slice per feature
  • Avoid large monolithic store
  • Keep store aligned with routing

Feature Store Setup using createFeature()

                                
                              export const counterFeature = createFeature({
                                name: counterFeatureKey,
                                reducer: createReducer(
                                  initialState,
                                  on(increment, (state) => ({ ...state, count: state.count + 1 })),
                                  on(decrement, (state) => ({ ...state, count: state.count - 1 })),
                                ),
                            });
  • Less boilerplate code: automatically generated selectors for fields

Use NgRx-Entity Adapter for Collections

                                
                                export interface UserState extends EntityState<User> {
                                    <..additional Properties..>
                                }
                                
                                const userAdapter = createEntityAdapter<User>({
                                  selectId: (user: User) => user.id,
                                });
  • Use entity adapter for CRUD operations
    • userAdapter.addOne()
    • userAdapter.updateOne()
    • userAdapter.removeOne()
    • userAdapter.addMany()
    • userAdapter.upsertMany()

Store Reset on Logout

                                
                                 export function clearState(reducer) {
                                    return (state, action) => {
                                        return action.type === '[Auth] Logout Success'
                                          ? reducer(undefined, action)
                                          : reducer(state, action);
                                    };
                                 }
  • Clean state to prevent data leaks

Advanced Effects

Effect Logic & Dispatching

  • Side effects examples:
    • Remote endpoint invocation
    • Navigation
    • LocalStorage updates
    • Notifications
    • Logging
  • Dispatch multiple actions from one effect
                                    
                                     return of(action1(), action2());

Error Handling in Effects

  • Use catchError inside effect pipelines
  • Dispatch an error action
  • Don't swallow errors silently
                                    
                                     catchError(error => of(actionOnFailure({ error })));

Advanced Selectors

Composing Selectors

                                
                                const selectFeature = createFeatureSelector<UserState>('user');
                                const selectUsers = createSelector(selectFeature, s => s.users);
  • Break large selectors into composable units
  • Avoid repeating logic in components
  • Keep selectors pure, reusable, and memoized

Parameterized Selectors

  • Ideal for list/detail views
  • Automatically memoized by argument
  • Efficient and reusable in components
    •                             
                                 selectUserById = (id: string) =>
                                    createSelector(selectUsers, users => users.find(u => u.id === id));

Best Practices

Do:

  • Use selectors + OnPush for performance
  • Split state by feature
  • Keep effects clean and purposeful
  • Store ID references instead of entire objects
  • Store only relevant data

Don't:

  • Store modal open/close UI flags globally
  • Write effects with no side-effects
  • Keep unrelated state in one slice
  • Store values that can be derived
  • Store data redundantly also in services, components etc.

Extension or Alternative to global Store: NgRx-SignalStore

                                
                             export const CustomerStore = signalStore(
                              withState({
                                customers: [] as Customer[],
                                selectedCustomerId: null as string | null,
                              }),

                              withMethods((store) => ({
                                selectCustomer(id: string) { },
                              }))
                             );
  • For data that is not needed globally
  • Less boilerplate code: without actions, selectors, reducers
  • Native Angular Signals Integration
