Effects vs. Computed Signals

Which one I should use?

Effects vs. Computed Signals

Use Cases for Computed Signals
  • Calculation should return a value and can be done with pure functions
  • Deriving reactive values
  • No side effects - signal caches its result until dependencies change
Use Cases for Effects
  • Performing side effects as logging, API calls
  • Trigger external actions

Outputs

View Child Signals

View Child signals replace the old @ViewChild() decorators
  • The view child can also be defined as required.
  • There is also a viewChildren function for more than one element

Content Child Signals

Content Child signals replace the old @ContentChild() decorators
  • The content child can also be defined as required.
  • There is also a contentChildren function for more than one element

Linked Signals

Linked signals are similar to writable signals, but they also react to changes of another source signal

Value can be changed

  • by set function
  • by value change of the source signal
